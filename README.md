# BODYCAM EXPERIENCE

Official releases of **BODYCAM EXPERIENCE** for PAYDAY 2.

BODYCAM EXPERIENCE is a bodycam-inspired first-person experience featuring independent weapon movement and FreeAim, designed and tuned specifically for PAYDAY 2.

## Download

The latest stable version is available from the **Releases** section of this repository.

Download the `BODYCAM-X.X.X-release.zip` file from the latest release.

## Installation

1. Make sure SuperBLT is installed.
2. Download the latest `BODYCAM-X.X.X-release.zip`.
3. Extract the `BODYCAM` folder into your PAYDAY 2 `mods` directory.
4. Launch PAYDAY 2.

The final installation should look like:

`PAYDAY 2/mods/BODYCAM/`

Older experimental builds and development versions are preserved separately in the **BODYCAM EXPERIENCE Development History** repository.
